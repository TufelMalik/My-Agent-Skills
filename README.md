# My-Agent-Skills

Portable agent skill collection imported from the GitHub sources below.

Each `SKILL.md` retains its upstream content. Where a top-level version was absent, a version line was added at the start of the existing YAML frontmatter; any upstream nested version value remains present. Existing top-level version lines are preserved. Supporting files were copied verbatim with their original relative paths. Upstream license and notice files are retained with the relevant skill. The source version column below uses the version declared by the upstream skill/package, or a pinned upstream commit when the source has no release version. The added top-level `version: 1.0` line is a local tracking tag, not an upstream release version.

## Scope notes

- The duplicate Anthropic repository tab was imported once.
- The typography repository tab pointed directly to `better-typography/SKILL.md`; sibling skills were not included.
- `awesome-claude-code` is a catalog of links and does not contain a skill package to copy.
- Anthropic's `docx`, `pdf`, `pptx`, and `xlsx` skills are described by their source repository as source-available rather than open source; their included license terms restrict copying and redistribution. They were excluded. `doc-coauthoring` and the repository template were also excluded because they are not marked with a redistributable skill license / standalone skill.
- The `career-ops` skill routes to its separate repository for its modes and scripts; its source `SKILL.md` states those dependencies explicitly.
- `cinematic-reel-editor` has no public upstream repository or published source version; it is identified as a custom skill rather than assigned a fabricated upstream version.
