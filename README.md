# My-Agent-Skills

Portable agent skill collection imported from the GitHub sources below.

Each `SKILL.md` retains its upstream content. Where a top-level version was absent, a version line was added at the start of the existing YAML frontmatter; an upstream nested version value is reused when present. Existing top-level version lines are preserved. Supporting files were copied verbatim with their original relative paths. Upstream license and notice files are retained with the relevant skill.

## Scope notes

- The duplicate Anthropic repository tab was imported once.
- The typography repository tab pointed directly to `better-typography/SKILL.md`; sibling skills were not included.
- `awesome-claude-code` is a catalog of links and does not contain a skill package to copy.
- Anthropic's `docx`, `pdf`, `pptx`, and `xlsx` skills are described by their source repository as source-available rather than open source; their included license terms restrict copying and redistribution. They were excluded. `doc-coauthoring` and the repository template were also excluded because they are not marked with a redistributable skill license / standalone skill.
- The `career-ops` skill routes to its separate repository for its modes and scripts; its source `SKILL.md` states those dependencies explicitly.
